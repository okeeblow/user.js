Any time I would toggle a setting in `about:config`, I set it here instead so new browser installations can be great by default.

Use with https://github.com/arkenfox/user.js/

TL;DR: In any Firefox profile directory…
- `git --git-dir=/dev/null clone --depth=1 https://github.com/arkenfox/user.js.git`
- `git clone https://github.com/okeeblow/user.js.git`
- `./updater`
